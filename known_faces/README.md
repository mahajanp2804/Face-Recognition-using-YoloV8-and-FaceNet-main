# known_faces

Put one folder per person here, named after them, with a few clear photos of their face:

```
known_faces/
├── Alice Smith/
│   ├── 01.jpg
│   └── 02.jpg
└── Bob Lee/
    └── 01.jpg
```

Supported formats: `.jpg`, `.jpeg`, `.png`, `.bmp`. 3–5 photos per person with different angles and lighting work best.

This folder's contents are ignored by git, so photos stay on your machine.
